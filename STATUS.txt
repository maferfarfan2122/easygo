┌───────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                               │
└───────────────────────────────────────────────────────────────────┘

❌ "OPENAI_API_KEY no configurada"
   → Edita backend/.env y agrega tu API key

❌ "Failed to fetch"
   → Verifica que el backend esté corriendo: http://localhost:8000

❌ "Module not found" (Python)
   → cd backend && source venv/bin/activate && pip install -r requirements.txt

❌ "Cannot import CVBuilder" (TypeScript)
   → Verifica tsconfig.app.json tiene "allowJs": true ✅

❌ El PDF no se descarga
   → Verifica que tengas créditos en OpenAI
   → Intenta "Generate Standard CV" (sin IA)
